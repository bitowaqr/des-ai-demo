# GEMINI PROMPTS

## Prompt 1:

develop a discrete event simulation model to assess the cost-effectiveness of a made up drug called supimab, compared to dupimab, for submission to NICE HTA approval. Supimab is a fictional innovative drug to prevent strokes. Create a dashboard to Visualise the results. Use d3 charts. Implement´ a nice and pleasing colour theme and layout (take studio ghibli as inspiration). You can make up any costs, health state utilities, QALYs, health events, outcomes, etc as this is just a demo exercise to showcase how good AI Coding Agents have become. What is important though is that you implement a sound discrete event simulation model that can be modified and reused. 
Important: Discrete Event Simulations (DES) operate in continous time, draw events from exponential time distributions: The simulation progresses as events occur, and the simulation clock jumps from one event time to the next to draw the next event. 
The model horizon is 5o years. The base population are patients with high risk of stroke, 50 years of age.
